# Deferred paper schematic review experiment

This folder preserves the deterministic connectivity JSON, SVG renderer,
generated StrongARM/Banba diagrams, review notes, and tests created during the
paper-schematic review experiment.

The experiment is intentionally not connected to the active design flow yet.
The current transistor drawing style still needs revision before the artifacts
are suitable for human schematic approval.

The archived tree preserves the files' intended repository-relative locations
under `Agent_LLM_BO/` and `knowledge_base/` so they can be restored or revised
later without reconstructing the work.
